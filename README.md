# Tetris - Unity

Unity oyun motoru ve C# kullanılarak geliştirilmiş klasik bir Tetris oyunu klonu.

## 🕹️ Açıklama

Bu proje, ikonik Tetris oyununun temel mekaniklerini Unity ortamında yeniden yaratmayı amaçlamaktadır. Blokların düşmesi, döndürülmesi, sıraların temizlenmesi ve puanlama gibi temel özellikler içerir.

## ✨ Özellikler

* Klasik Tetris oyun mekaniği
* Blokları hareket ettirme ve döndürme
* Tamamlanan sıraları temizleme
* Puanlama sistemi
* (Varsa ek özelliklerini buraya listele, örneğin: Seviye sistemi, artan hız, sonraki blok göstergesi vb.)

## 💻 Kullanılan Teknolojiler

* Oyun Motoru: Unity (Kullandığın sürümü belirtebilirsin, örn: 202X.X.X)
* Programlama Dili: C#

## 🚀 Kurulum

1.  Bu repoyu bilgisayarınıza klonlayın veya ZIP olarak indirin.
    ```bash
    git clone [https://github.com/Ali23579/tetris-unity.git](https://github.com/Ali23579/tetris-unity.git)
    ```
2.  Unity Hub'ı açın.
3.  "Add" veya "Open" seçeneği ile indirmiş olduğunuz proje klasörünü Unity'ye ekleyin.
4.  Projenin Unity editöründe açılmasını bekleyin.

## ▶️ Kullanım

1.  Unity Editöründe `Assets/Scenes` (veya ana sahnenin bulunduğu klasör) içerisindeki ana oyun sahnesini (`.unity` uzantılı dosya) açın.
2.  Editörün üst kısmındaki "Play" (▶️) düğmesine tıklayarak oyunu başlatın.
3.  (Varsa oyun kontrollerini buraya ekle, örn: Sol/Sağ Ok = Hareket, Yukarı Ok = Döndürme, Aşağı Ok = Hızlı İndirme)
